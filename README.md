# 折纸星球 OrigamiPlanet 🦊

把儿童折纸教程的详细步骤，变成**一步步会动的 3D 演示**。

- 每一折都是真实模拟：折痕切割纸面、谷折/山折、内翻折、沉折、翻面、塌缩、分层折叠，可以拖动旋转、暂停回看
- 教程本身是一份**可编程的步骤数据（IR）**——图文教程、视频教程都可以转写成这份格式并自动播放成 3D
- 内置 **25 个教程**：
  - **9 个经典款**：小狗头、小兔头、小纸杯、小房子、纸飞机、小折扇、东南西北、知了、爱心信封
  - **16 个来自公众号「折纸造物记」合集《折纸小玩具》的转换款**：指尖陀螺、折纸小兔、弹跳青蛙、搞怪便便、和平鸽、卡皮巴拉、折纸恐龙、折纸鲨鱼、折纸蝙蝠、弹力小蛇、腊肠犬、小公鸡、月兔、小猫猫、战斗机、河马

线上地址：<https://origmi3d.vercel.app>

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/

```

## 架构

```
src/
  engine/            # 折纸内核（与 UI 无关，可独立复用 / 移植到小程序、App）
    geometry.ts      # 2D/3D 几何：多边形裁剪、线段求交、Rodrigues 旋转
    fold.ts          # 折叠内核：步骤类型、折痕切割、层号重排、步骤编译
    scene.ts         # Three.js 渲染：双面双色纸面、折痕线、幽灵预览
    player.ts        # 播放器：上一步/下一步/自动播放/速度，动画帧驱动
  data/              # 教程 IR（每个教程一个文件，纯数据）
    tutorials/*.ts
    wechat-album.json # 公众号合集清单与转换状态
    util.ts          # 常用纸形（正方形 / 菱形 / 长方形）
  components/        # 首页 + 3D 教程播放页
scripts/
  run-check.mjs      # 引擎自检：编译全部教程，校验「折叠前后纸面积守恒」等不变量
tests/               # 穷举测试套件（数据驱动内容站七层模型）
  run-exhaustive.mjs # 一键运行 Node 端 L1-L5、L7 全量断言
  exhaustive.e2e.mjs # 无头 Chrome 线上/本地全路由走查
  manual-signoff.md  # 机器不可判定项（折纸动作词）人工签核清单
```

### 折叠内核的核心思想

- 纸 = 一组平面**面片**（face），每片带层号（stack）与折痕印记
- 一次折叠：
  1. 用折痕**线段**切开受影响的面片（折痕必须以正长度穿过面片才切割，擦边不切——这样"沿中缝对折"才正确）
  2. 移动侧绕折痕轴旋转到目标角度（谷折朝观察者抬起，山折相反）
  3. 按层号规则重新落位，层号差换成微小 z 偏移避免 z-fighting
- 支持的步骤类型：`fold`（谷/山折，支持分层与全幅）、`prefold`（压痕）、`reverse`（内翻折/外翻折，含 `sink` 沉折动画）、`flip`（翻面）、`collapse`（塌缩：水气球/风车基础形，逐面片刚性旋转）、`pose`（立体整形：逐面片形变插值）、`note`（讲解）
