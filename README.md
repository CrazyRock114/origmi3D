# 折纸星球 OrigamiPlanet 🦊

把儿童折纸教程的详细步骤，变成**一步步会动的 3D 演示**。

- 每一折都是真实模拟：折痕切割纸面、山折/谷折、翻面、分层折叠，可以拖动旋转、暂停回看
- 教程本身是一份**可编程的步骤数据（IR）**——图文教程、视频教程都可以转写成这份格式并自动播放成 3D
- 内置 10 个教程：小狗头、小兔头、小纸杯、小房子、纸飞机、小折扇、东南西北、知了、爱心信封，以及**指尖陀螺**（首个从微信公众号图文转写的立体教程）

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/
node scripts/run-check.mjs   # 引擎几何自检（面积守恒、层数、NaN 检查）
```

## 架构

```
src/
  engine/            # 折纸内核（与 UI 无关，可独立复用 / 移植到小程序、App）
    geometry.ts      # 2D/3D 几何：多边形裁剪、线段求交、Rodrigues 旋转
    fold.ts          # 折叠内核：步骤类型、折痕切割、层号重排、步骤编译
    scene.ts         # Three.js 渲染：双面双色纸面、折痕线、幽灵预览
    player.ts        # 播放器：上一步/下一步/自动播放/速度，动画帧驱动
  data/              # 教程 IR（每个教程一个文件，纯数据）
    tutorials/*.ts
    util.ts          # 常用纸形（正方形 / 菱形 / 长方形）
  components/        # 首页 + 3D 教程播放页
scripts/
  run-check.mjs      # 引擎自检：编译全部教程，校验「折叠前后纸面积守恒」等不变量
```

### 折叠内核的核心思想

- 纸 = 一组平面**面片**（face），每片带层号（stack）与折痕印记
- 一次折叠：
  1. 用折痕**线段**切开受影响的面片（折痕必须以正长度穿过面片才切割，擦边不切——这样"沿中缝对折"才正确）
  2. 移动侧绕折痕轴旋转到目标角度（谷折朝观察者抬起，山折相反）
  3. 层号重排：移动包按倒序落在停留层之上（谷折）/之下（山折）
  4. 层号换算成微小 z 偏移，避免共面面片 z-fighting
- 翻面 = 整体绕面内轴旋转 180°，层序颠倒
- 预折痕 = 折过去再折回来，只留下折痕印记
- `layersMin / layersMax` 支持经典折法里的"只折最上面一层 / 不带已折好的部件"

## 教程 IR（中间格式）

每个教程是一个纯数据对象（`src/engine/fold.ts` 中的 `Tutorial` 类型）：

```ts
{
  id: 'dog', title: '小狗头', emoji: '🐶',
  category: '动物', difficulty: 1, minutes: 3,
  intro: '…',
  paper: { outline: DIAMOND, front: '#FFF9F0', back: '#C68642' }, // 纸形与正/背颜色
  steps: [
    // 谷折 / 山折：折痕线段 a-b，移动侧内任取一点 m，angle 默认 180°
    { type: 'fold', a: v(-1,0), b: v(1,0), m: v(0,1), dir: 'valley',
      layersMin?: 2, layersMax?: 4, angle?: 150, desc: '把左边的角…', tip: '…' },
    // 预折痕：折过去再折回来，留下折痕
    { type: 'prefold', a: v(0,-1), b: v(0,1), m: v(-0.4,0), desc: '对折出中线再展开' },
    // 翻面：绕 x（俯视竖直镜像）或 y（水平镜像）轴
    { type: 'flip', axis: 'y', desc: '翻个面' },
    // 立体聚合：风车基础形、锥体立起等整体收拢动作，直接给出目标面片几何，
    // 播放时以"收拢→绽放"变形过渡（spin 为过程中的绕 z 扭转弧度）
    { type: 'pose', faces: [{ pts: [[0.5,0,0],[0,0.5,0],[-0.5,0,0],[0,-0.5,0]], stack: 2 }, …],
      spin: -Math.PI/2, desc: '捏住四边向中心靠拢…' },
    // 纯讲解步骤（如"画上眼睛"）
    { type: 'note', desc: '完成！' },
  ],
  source: { label: 'Origami Fun · Origami Dog Face', url: 'https://…' },
}
```

坐标约定：纸张位于 XY 平面，z 朝观察者；`a/b/m` 写在**当前步骤俯视视角**的坐标系里（和纸样图一致，折一步更新一次坐标）。技术要点：

- 折痕坐标要用**精确值**（如 `1.2 - k*2.4/7`），四舍五入会让后续步骤的落点错位（见折扇的教训）
- 需要左右对称的两折，方向相同（都 valley 或都 mountain），镜像由折痕朝向自动处理
- 每 500ms 级别的正确性由 `node scripts/run-check.mjs` 兜底：折叠是等面积变换，面积不守恒 = 步骤写错了

## 外部教程导入管线（已跑通第一条）

产品的核心能力是把公众号图文、B 站视频、小红书笔记转成 3D 演示。**指尖陀螺教程即第一条完整跑通的管线样例**：

1. **取材**：微信公众号《[解锁好玩的指尖陀螺](https://mp.weixin.qq.com/s/07N5r097JTl2w8k-PyN0SQ)》（折纸造物记）——浏览器渲染页面（绕过环境验证）→ 提取图集全部图片 URL → 下载
2. **结构化**：逐张读图，把每一步转写成 IR——平面折（对角线/十字/四分线预折痕、四角折心）用 `fold/prefold`；**立体聚合**（风车基础形、锥体立起、叶片内凹）用 `pose` 步骤给出目标几何
3. **校对**：自检脚本（NaN/可编译检查，pose 步骤跳过面积守恒）+ 浏览器里逐步对照原图核对
4. **发布**：IR 进入 `src/data/tutorials/spinner.ts`，注册即上线

IR 是整个管线的"汇"：任何来源的教程只要转写成 IR，播放器无需改动。后续把第 2 步换做多模态模型自动化、第 3 步做成可视化步骤编辑器即可规模化。

## 折叠算子的 IR 表达模式

实现进阶折法时优先复用现有步骤类型（无需改内核）：

- **内翻折（inside reverse fold）** = `fold` + `layersMin/layersMax` 限定到对应的层组。
  几何终点与普通折叠一致；双面渲染自动呈现"翻色"效果。`desc` 中注明"内翻折"即可。
- **Squash fold（挤压成正方形）** = `collapse` 的子区域表达：`faces` 给出压平后的方形两片
  （`from` 为原口袋位置），铰链可选。
- **手风琴/N 形褶皱** = 交替 `dir: 'valley' / 'mountain'` 的连续 `fold`。
- **立体面片连通性**：折叠内核对"显著倾斜的面片"（z 跨度 > max(0.05, 平面尺寸×12%)）
  不做切分——它们通过根部附着在一侧纸面上，随附着侧整体翻转（如塌缩后立起的腿）。
  微倾面片（如刚压平的水气球层）仍按平面切分。

## 已知边界（下一步的引擎工作）

- `pose` 步骤的"收拢→绽放"是形变过渡而非逐面物理折叠——足够传达立体聚合的动作要领，
  下一步可为常用聚合（风车基础形、Square Base、Inside Reverse Fold）内置带对应关系的真实形变算子
- 千纸鹤、青蛙等模型将在上述算子就绪后接入
- 层号是相对序，超厚模型（>10 层）的 z 偏移会略微夸张（教学上反而更清晰，可调 `STACK_EPS`）
- 展示类收尾（撑开纸杯、套手指）目前用 `note` 步骤 + 图文说明
